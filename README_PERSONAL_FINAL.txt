AUTOCAT-JP PERSONAL FINAL

個人Owner専用ビルド。

残しているもの:
- 元のWeb版に含まれるにゃんこ大戦争のデータ処理・代行ジョブ
- キャラクター/ステージ等の編集機能
- ジョブ進捗・結果確認
- Ownerだけが利用できるローカルログイン

削除したもの:
- 外部チャット・外部ログ送信機能
- 外部決済・購入システム
- チャット / DM / Browser Push
- 招待・無料利用回数管理・外部サービス向け機能
- 外部プロキシ設定

重要:
- 代行処理そのものに必要なゲーム側/BCSFE通信は残る。
- このビルドには外部チャット・外部決済・外部ログ送信機能を含めていない。
- Replit等の第三者クラウドへアップロードすれば、そのクラウドにはソースコードを預けることになる。

起動:
1. Python環境を用意
2. requirements.txtをインストール
3. LOCAL_ADMIN_PASSWORDを設定
4. python main13.py
5. http://127.0.0.1:1142/ を開く
